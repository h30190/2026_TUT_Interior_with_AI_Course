# Skill：磁磚排磚與損耗量 ABC 方案比較

供 AI Agent 調用：輸入空間與磁磚參數，輸出齊貼/交丁三方案的片數、損耗率與決策建議。

## 1. 排磚位移公式定義

以「列」為沿空間長度 L 方向的一排磚，r 為列序（r = 0, 1, 2...），T_L 為磚長。

| 工法 | 第 r 列偏移量 offset |
|---|---|
| 齊貼（橫貼/直貼） | `offset = 0` |
| 5/5 交丁 | `offset = (r mod 2) × 0.5 × T_L` |
| 3/7 交丁 | `offset = (r × 0.3 × T_L) mod T_L` |
| 2/8 交丁 | `offset = (r × 0.2 × T_L) mod T_L` |

起磚基準：
- 角落起磚（Corner）：第一列起點 = offset。
- 中軸對齊（Center）：第一列起點 = (L − T_L)/2，其後各列再加 offset。

## 2. 損耗判定準則

### 幾何原因（切料不可復用）
- 齊貼：只有最後一列/最後一排被牆面截斷，裁切寬度取決於 L、W 是否為磚尺寸整倍數；若整除則零裁切。
- 交丁：每列起點錯位，導致**每一列的末端都被截斷**，且截斷寬度各列不同。交丁步距與磚長不成整數倍關係（3/7、2/8 尤甚），裁切片無法湊回一整片復用，故叫料必然高於理論片數。
- 5/5 是 1/2 倍關係，兩列一循環，損耗較規律；3/7、2/8 循環較長（10 列、5 列才重複），列數越多、末端碎料越多。

### 碎料判定
- **危險碎磚**：裁切後面積 < 1/4 單磚面積，或任一邊 < 5 cm。
- 判定時機：每塊裁切磚計算 `wL × wW`（實際保留尺寸），與 `T_L × T_W` 比較。
- 实务意義：<5 cm 的條狀碎磚無法穩定粘貼、易空鼓斷裂，視為損耗而非可用料。

## 3. ABC 方案輸出格式（Markdown 表格樣板）

| 方案 | 理論片數 | 實鋪整磚 | 邊緣裁切 | 總叫料 | 損耗率% | 總金額 | 價差 |
|---|---|---|---|---|---|---|---|
| A 橫貼齊貼 | ... | ... | ... | ... | ... | ... | — |
| B 直貼齊貼 | ... | ... | ... | ... | ... | ... | ... |
| C 交丁(5/5/3/7/2/8) | ... | ... | ... | ... | ... | ... | ... |

計算定義：
- 理論片數 = ⌈(L×W)/(T_L×T_W)⌉
- 總叫料 = 整磚 + 裁切消耗（裁切不可回填）
- 損耗率 = (總叫料 − 理論片數) ÷ 理論片數 × 100%

### 決策依據（結論卡樣板）
> 方案 X 比方案 A 多耗 N 片，損耗率高出 p%，但能避免長條磚中央拱起問題／存在 M 塊危險碎磚，建議改用中軸對齊或調整步距。

Agent 產出時必須：① 三方案同表呈現 ② 標出最省方案 ③ 若有 <1/4 磚或 <5 cm 碎料，明確警告並給調整建議 ④ 數字抽兩三筆手算驗證（接 10/03「自我檢查不叫驗證」原則）。
