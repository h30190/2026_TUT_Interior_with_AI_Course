# 磁磚放樣施工圖系統｜操作說明

> 一句話：把 DXF 拖進網頁 → 確認 → 自動找起磚點 → 匯出 DXF 貼回 AutoCAD。

## 打開

1. 下載或 `git pull` 這個資料夾。
2. 用 Chrome 或 Edge **雙擊 `index.html`**，不用安裝任何東西。

## 每個案子 4 步

| 步驟 | 做什麼 | 注意 |
|---|---|---|
| ① 拖 DXF 進來 | AutoCAD「另存新檔」選 DXF，把檔案拖進網頁（或按「📐 匯入 DXF」） | 一個檔有很多間浴室會跳清單讓你選 |
| ② 確認 | 看跳出來的「請確認」，檢查四面尺寸、門窗、材料 | 讀錯的直接在「五面控制面板」改 |
| ③ 自動找起磚點 | 按「🧠 自動找最佳起磚點」，比較方案後按「套用」 | 依序比：L 型 → 小料 → 浪費 |
| ④ 出圖 | 📐 匯出 DXF／🖨️ 匯出 PDF／💾 匯出資料檔 | 資料檔下次可以「匯入資料檔」接著改 |

整份 DXF（很多間）：在選圖視窗按「📚 全部匯出 PDF」或「📊 下載全案總叫料表 CSV」，拿去叫料。

## 兩種 DXF 都可以

**有立面施工圖**（照平常畫法）：立面外框下方有 A/B/C/D 索引、色號 62「由此線開始放樣」、紅線色號 1、門窗青色色號 4、材料文字含「填縫劑」。

**只畫地坪**（比較快）：
- 房間中間放 ABCD 視角符號，或只畫一條地坪外框（封閉聚合線）；整張平面圖也行，會跳出來讓你點浴室。
- 牆線用同一種顏色，房間裡**不要畫磚縫線**，比較不會判讀錯。
- 門用開門弧線（約 90°），門窗畫青色（色號 4），窗洞讓牆斷開——程式量牆的開口當門寬、窗寬。
- 窗的左右位置照平面，窗台和窗高平面看不出來。
- 半高檯（管道間、隱藏水箱）：在平面上沿牆畫**紅線**（色號 1）＝檯的正面，端點畫一小段紅線接回牆＝側面。
- **匯入前會跳「確認高度」視窗**：牆高、門高、窗台／窗高、檯高一次填（黃色的是預設值，照設計圖改），順便勾要出哪幾面立面。
- 高度寫在圖上也讀得到：`天花 FL+289`、`門高 239`、`檯高 110`。
- 凹凸的牆（例如底牆往內一階）：一階的側面畫在看得到它的那面立面，轉折處記在「牆面轉折 X」（不同平面，跨過的磚會切開，畫紅線）。

## 半高檯（管道間、隱藏水箱）

- 「半高檯」卡片：靠哪面牆、正面距左、長、高、深、側面攤開（不攤／右邊／左邊）。
- 檯的正面、側面跟上面的牆不同平面：跨過檯緣的磚會切開；包住檯角算 L 型（橫縫對齊檯面就避開了）。
- 側面攤開＝側面畫進這面立面，牆寬自動加檯深（例如 B 牆 193＋6＝199）；攤開那條的上方沒有牆，不貼磚。
- 檯靠著的另一面牆被擋住的一段、地坪被檯佔掉的地方不貼磚（淡灰底、紅線框）。
- 跨過檯緣切開的兩塊各算一片；要拿同一片切開兩邊用，勾「剩料回收」。檯面（頂面）不算料。

## 同一面混 2～3 種磚（分區欄位，分號隔開，後寫的蓋在上面）

```
117-207: 14.8×14.8 主秀壁          ← 左右分區（距左 117～207）
高 0-120: 30×60 下段                ← 上下分段（離地 0～120）
高 100-130: 15×30 腰帶              ← 腰帶
117-207: 14.8×14.8 主秀壁; 高 100-130: 15×30 腰帶   ← 腰帶橫跨主秀壁
```

欄位下方有「＋左右分區／＋上下分段／＋腰帶」按鈕可以塞範本。腰帶上方的磚會從腰帶上緣重新起磚。

## 程式用的規則（都是依我的現場經驗定的）

- **小料**：裁切後露出部分最短邊 < 5 cm（可改）；同一排小料只圈一次。磚本身 ≤ 5 cm（小馬賽克）不算。
- **L 型切割**：磚包住門窗或分區轉角就算，再小都算，優先避開。
- **牆底被地磚蓋住**：預設 1 cm（可改），牆底這個高度以內的切條不用貼、不算小料。
- **叫料**＝整磚＋裁切磚；不同尺寸分開算；下單＝叫料×(1＋備品%) 無條件進位。
- **剩料回收**：勾了才算進報價（切邊能不能露出來要現場判斷）。

## 匯出的 DXF 怎麼貼回 AutoCAD

- 圖層：牆磚縫「壁磚」、地坪「地磚」，Hatch 在「壁磚-HATCH／地磚-HATCH」（可以單獨關閉），尺寸「T-DIM」（樣式「複本 ISO-25」）。
- 單位 1＝1 cm，檔頭跟原圖一樣寫 mm：用 **INSERT** 插入不會被放大縮小；名稱相同的圖層、尺寸樣式會併到原圖。
- 排法：上排 A、B、C、D 立面，下排地坪對齊 B；地坪右邊有磁磚圖例。

## 常見問題

- **讀不到圖**：DXF 要「另存新檔」存，不是 DWG 改副檔名。
- **只有地坪時房間框錯**：在選房間視窗直接點在浴室中間（離牆、設備遠一點）。
- **門的位置／寬度不對**：在「門窗」清單改；平面的開門弧線是門片寬，程式會盡量量牆的缺口。
- **改了門寬畫面沒變**：看門窗卡片上的紅字，多半是門超出牆寬被截掉（牆寬可能抓錯，先確認五面尺寸）。
- **空間 L／W／H**：L＝A、C 牆長（地坪深），W＝B、D 牆長（地坪寬），H＝牆高；改哪個只動哪幾面。
- **想改規則或加功能**：叫 AI（Antigravity／OpenCode）先讀 `AGENTS.md` 再改，改完跑 `tests\ci.ps1`。
