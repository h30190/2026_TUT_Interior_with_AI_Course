## 今天做什麼

今日主題：資料分析與重複規格工具——**磁磚排磚損耗量 ABC 方案分析**。

用 agent 建立一個單檔網頁應用，同時比較三種排磚方案（A 橫貼齊貼、B 直貼齊貼、C 交丁 5/5/3/7/2/8）的理論片數、實鋪整磚、邊緣裁切、總叫料、損耗率與價差，並用 Canvas 即時視覺化排磚圖，標示危險碎磚。

## 產出

- `index.html`：單檔網頁應用（HTML + Vanilla CSS + Vanilla JS，免 npm），瀏覽器直接點開即可。
  - 使用方式：填入空間尺寸、磁磚尺寸、磚縫、單價與起磚方式 → 自動產生 ABC 對比總表與結論卡；下方按鈕切換 A/B/C 方案的 Canvas 排磚圖（整磚米白、裁切橘、危險碎磚亮紅）。
  - 快速情境：客廳大板磚 / 主臥木紋磚 / 浴室壁磚 一鍵帶入。
- `skills/tile-layout-loss/SKILL.md`：排磚位移公式、損耗判定準則、ABC 輸出格式，供 AI Agent 調用。

## 最卡的地方

- 交丁的「列偏移」要依步距逐列計算：5/5 是兩列一循環、3/7 與 2/8 循環較長，列數越多末端碎料越多，這正是交丁損耗一定高於齊貼的幾何原因。
- 危險碎磚判定（<1/4 磚或 <5 cm）在窄磚（如主臥木紋磚 15×75）最容易觸發——同一塊裁切磚「面積比例」和「最短邊」兩個條件要分開檢查，只比面積會漏掉細長條。
- 中軸對齊 vs 角落起磚會直接改變兩端的裁切寬度，同一方案兩種起點損耗可能差很多，這是最需要跟業主溝通的點。

## 後續更新（10/19）：從「算料」升級成「放樣施工圖」

程式已拆成 `index.html＋css/＋js/` 多檔（瀏覽器直接開 `index.html`，免安裝）。

- **📐 匯入 DXF**：AutoCAD「另存新檔 → DXF」後匯入，程式自動找出檔案裡每一張放樣施工圖讓你挑（實測 20MB、18 張圖約 2 秒）。依我的畫圖習慣判讀：
  - 立面外框＝封閉矩形＋下方 A/B/C/D 索引圖塊；地坪＝ABCD 視角符號所在的平面外框
  - 「由此線開始放樣」＝色號 62 引線碰到立面頂邊的位置；紅線＝立面內紅色垂直線
  - 門窗＝立面內青色矩形（貼地＝門）；材料＝「壁／地／主秀壁＋型號＋尺寸＋填縫劑」文字
- **💾 施工圖資料檔（JSON）**：匯出／匯入整張圖的尺寸、起磚、紅線、門窗、材料
- **施工圖畫法**：分段尺寸鏈、綠色「由此線開始放樣」、紅線、索引符號、材料表
- **🎨 彩色方案／✏️ 施工線稿** 切換：給業主看損耗 vs 給師傅放樣
- 每面可設自己的磚（例如地坪 120×60、牆 120×120）
- **同一面多種磚（分區）**：例如 B 面「117-207: 14.8×14.8 主秀壁」，分區外沿用該面的磚；各區各自起磚、各自算料，算料表依材料分開合計。DXF 匯入時會依紅線切段、看磚縫間距自動判斷分區（主秀壁與壁磚同尺寸時無法判斷，會提示手動設定）

- `node tests/browser-test.js`：真的打開網頁按遍所有按鈕、匯入匯出、DXF、PDF（第一次先 `npm install -g playwright` 和 `npx playwright install chromium`；沒裝會自動略過）

- **設備與備註**：DXF 立面／平面範圍內的設備線稿（馬桶、臉盆、門、檯面，含圖塊）、文字、多重引線備註（例如「因馬桶位置提高一塊磚」）照原座標與顏色搬過來畫
- **小料規則**：只看裁切後露出部分的最短邊，< 5cm 為小料（計入碎磚警示）並在圖上紅圈標「避免小料」；磁磚本身 ≤ 5cm 不列入（兩個門檻可分開調，例如紅圈只圈 < 3cm）

- **L 形／斜牆地坪精確算料**：地坪外框可以是任意多邊形，每塊磚跟外框裁切，照實際露出形狀算整磚／裁切／小料與理論片數；DXF 平面內框沒封閉時用直角補起（門檻不算）
- **立面↔平面左右關係**：站在房間裡面向牆看，A、D 面與平面左右相反（門窗、結構柱、尺寸鏈、地壁對縫都已換算；平面上拖柱子會沿著牆的方向走）

- **此面不鋪磚**：每面可勾選（油漆牆、圖上沒有的立面）；DXF 少了某一面時自動勾選
- **手動地坪外框**：地坪設定的「外框頂點」欄位可直接輸入 x,y（由左上量），沒有 DXF 或 DXF 判斷不出時手動修正
- **直線畫的地坪／斜牆**：沒有外框聚合線時，從 ABCD 視角符號往四周找最近的牆線，四面牆延長線兩兩相交圍成四邊形（梯形房間也準）
- **🖨️ 匯出 PDF／🖼️ 下載圖片**：A3 橫式兩頁（第 1 頁施工圖＋圖框標題欄與「尺寸若有誤差 依現場放樣 再行溝通」，第 2 頁材料表＋五面算料表），在列印視窗選「另存為 PDF」；圖片為 3 倍解析度 PNG
- **📚 整份 DXF 一次匯出**：選圖視窗可「全部匯出 PDF」（第一頁全案總叫料表：同用途＋型號＋尺寸合計、各圖明細與需要確認事項，之後每張浴室一頁施工圖）或「下載全案總叫料表 CSV」（Excel 可開）；算完自動恢復原本畫面
- **💰 報價**：材料卡片填單價（以型號為準，換圖、整份匯出共用，瀏覽器會記住）、設定備品 %；下單片數＝叫料×(1＋備品%) 無條件進位，算料表下方列出各材料金額與合計，單張 PDF、全案總叫料表與 CSV 都帶金額（全案是合計後才加備品）
- **✂️ 裁切清單與剩料回收**：每面要切的磚（寬×高，被門窗或收邊蓋住的不用切）；同材料大塊先切、剩料夠大就拿去切下一塊（扣鋸路 0.3cm、長方形磚不轉向），算出可少開幾片；勾「採用剩料回收」後報價與全案總叫料表改用回收後片數（實測 18 間浴室共 2553 片 → 2187 片，省 366 片）
- **🏠 只畫地坪就好**：DXF 裡沒有立面施工圖時，當成只有地坪平面——ABCD 視角符號、一條外框、整張平面圖（跳視窗點一下浴室）都可以；四面牆由地坪四邊產生，牆高、門高讀圖上「天花 FL+289」「門高 239」這類文字，沒寫就用網頁的 H 與「門高」預設；開門弧線自動找門（量牆線缺口當門框外寬）；牆斷開處有青色窗線就是窗，左右位置與寬度照平面、窗台與窗高用網頁預設（90／120）；匯入後自動套用最佳起磚點
- **門窗超出牆面會警告**：門窗清單卡片上直接寫「超出 C 牆寬 113：寬只畫到 63」，不會再默默截掉
- **改空間長寬高不再洗掉匯入的尺寸**：L＝A、C 牆長（地坪深）、W＝B、D 牆長（地坪寬）、H＝牆高，改哪個只動哪幾面（修正地坪長寬顛倒的問題）
- **📥 拖拉匯入**：DXF 或資料檔（JSON）直接拖進畫面就匯入
- **🧩 同一面混 2～3 種磚**：分區欄位用分號隔開，**寫在後面的蓋在前面上面**——左右分區「117-207: 14.8×14.8 主秀壁」、上下分段「高 0-120: 30×60 下段」、腰帶「高 100-130: 15×30 腰帶」，也可以疊著用（主秀壁＋整面腰帶）；欄位下方有「＋左右分區」「＋上下分段」「＋腰帶」按鈕塞範本再改數字。每種磚各自算料、各自 Hatch，DXF 磚縫不會穿過上層分區，上下分段的高度會標在尺寸鏈；**腰帶（上下分段）上方的磚從它的上緣重新起磚**，下方照原本起磚
- **牆底被地磚蓋住**：參數「牆底被地磚蓋住 (cm)」預設 1（地磚＋黏著層至少墊高約 1cm），牆底在這高度內的切條不用貼、不算小料；整磚不受影響。存在資料檔裡
- **「避免小料」同一排只圈一次**：一整排（例如馬賽克頂端一排 6 片）只圈中間那片，片數照算（#18 DXF 紅圈 7 → 2、#17 21 → 2）
- **🧱 L 型切割檢查**：磚包住門窗轉角（要切成 L 型，兩刀、內角易裂、難對位）就算，再小都算——例如從地面排、門頂只多 1.2cm 的那片也算。算料表「碎磚警示」欄、提示列與結論列出片數，圖上（含 PDF、匯出 DXF）紅圈標在被包住的轉角、寫「避免L型」；全案總叫料表各圖明細多一欄 L 型
- **🧠 自動找最佳起磚點**：五面控制面板按一下，比較 4 個方案——目前設定、各面最省（每面在一個磚距內逐公分試，牆面也試上下：由地起、磚縫對齊門頂／窗台、每 10cm 粗掃）、四面對縫（試地坪起點、牆縫跟著地磚縫）、置中對稱；依序比 **L 型 → 小料 → 浪費面積**（牆底一點小料會被地磚蓋住，L 型優先避開），標 ★推薦，按「套用」改起磚設定（四面對縫會一併打開鎖定）。實測 18 間：推薦方案全部沒有 L 型（#18 自己找到橫縫 118.8／239，跟原施工圖一樣對齊門頂；#11 A 面對齊門頂後牆底剩 0.6cm，會被地磚蓋住）；分區馬賽克頂端小料也一起減少（#18 6 → 0、#14 23 → 10）
- **📐 匯出 DXF（貼回 AutoCAD）**：照我的施工圖畫法輸出——磚縫是單線（灰 8，牆在「壁磚」層、地坪在「地磚」層）、紅線色號 1、門窗色號 4、「由此線開始放樣」色號 62、尺寸是 T-DIM 層「複本 ISO-25」的真尺寸物件（可點選拉伸）、小料紅圈 r6＋「避免小料」、立面索引符號、地坪視角符號；牆高只標在 A 左側、門高標在該面右側。新圖從 0,0 排（上排 A～D 立面間距 80、下排地坪對齊 B），單位 1＝1 cm、檔頭跟原圖一樣寫 mm，在 AutoCAD 用 INSERT 插入不會被縮放；圖層與尺寸樣式名稱跟原圖相同，插入後併到原本的圖層
- **🎨 壁磚／地磚分開、每種磚不同 Hatch**：匯出 DXF 時磚縫分「壁磚」「地磚」兩層，Hatch 另放「壁磚-HATCH」「地磚-HATCH」（可單獨關閉）；每種磚依序配 ANSI31（黃）、ANSI34（橘）、ANSI37（綠）、ANSI32（青）、NET（洋紅），黑白列印也分得出來，地坪右邊附磁磚圖例；畫面「施工線稿」與 PDF 用同樣的 Hatch 和圖例
- **🏗️ Revit 外掛**（`revit-addin/`）：Revit 2024 選房間 → 匯出資料檔（地坪外框含 L 形、四面牆、門窗），網頁直接匯入；編譯與安裝見 `revit-addin/README.md`
- **材料表**：匯入的材料可編輯、新增，並上傳材質照片（縮成 200px 存進資料檔），照片畫在施工圖材料表旁
