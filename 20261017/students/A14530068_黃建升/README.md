## 今天做什麼

今日主題：資料分析與重複規格工具——**磁磚排磚損耗量 ABC 方案分析**。

用 agent 建立一個單檔網頁應用，同時比較三種排磚方案（A 橫貼齊貼、B 直貼齊貼、C 交丁 5/5/3/7/2/8）的理論片數、實鋪整磚、邊緣裁切、總叫料、損耗率與價差，並用 Canvas 即時視覺化排磚圖，標示危險碎磚。

## 產出

- `index.html`：單檔網頁應用（HTML + Vanilla CSS + Vanilla JS，免 npm），瀏覽器直接點開即可。
  - 使用方式：填入空間尺寸、磁磚尺寸、磚縫、單價與起磚方式 → 自動產生 ABC 對比總表與結論卡；下方按鈕切換 A/B/C 方案的 Canvas 排磚圖（整磚米白、裁切橘、危險碎磚亮紅）。
  - 快速情境：客廳大板磚 / 主臥木紋磚 / 浴室壁磚 一鍵帶入。
- `skills/tile-layout-loss/SKILL.md`：排磚位移公式、損耗判定準則、ABC 輸出格式，供 AI Agent 調用。

## 最卡的地方

- 交丁的「列偏移」要依步距逐列計算：5/5 是兩列一循環、3/7 與 2/8 循環較長，列數越多末端碎料越多，這正是交丁損耗一定高於齊貼的幾何原因。
- 危險碎磚判定（<1/4 磚或 <5 cm）在窄磚（如主臥木紋磚 15×75）最容易觸發——同一塊裁切磚「面積比例」和「最短邊」兩個條件要分開檢查，只比面積會漏掉細長條。
- 中軸對齊 vs 角落起磚會直接改變兩端的裁切寬度，同一方案兩種起點損耗可能差很多，這是最需要跟業主溝通的點。
