# 波浪曲面壁板製作決策程式

## 新增：使用者直接上傳造型

- 資料來源選擇「3D 模型」，上傳 binary/ASCII STL 或三角化 OBJ，確認 mm/cm/m、正面軸向及單面表皮比例。讀取三角面面積與外接尺寸；修改尺寸會等比例縮放模型。
- 圖面支援 PNG/JPG/WEBP。正投影圖可點兩點，填實際距離校正尺寸；也可自行輸入寬高、深度、輪廓占比與曲面積倍數。圖片模式為使用者補入尺寸的估算，無 AI 深度還原。
- 所有模式均連動原有成本、時間、材料、能源及排序。模型按表皮面積×指定厚度估料，不使用實心體積；封閉模型需自行指定正面表皮占總面積比例，避免把背面或側面都當裝飾表皮。
- 模型投影採外接矩形；木作骨架仍沿用示範假設。複雜孔洞與構造需校正。成本、品質及產能仍為使用者可調整假設。
- 限 20MB、100,000 三角面。OBJ 請三角化匯出；PDF/DWG/SKP 先匯出為支援格式。下載 `sample-panel.obj` 可測試：模型 mm，100×200×10cm，表面積約2.039608m²。
- 檔案僅在本機瀏覽器解析，重新整理後須重選，模型不存入 localStorage。CSV 包含檔名、面積、單位、軸向、曲面倍數與表皮比例。
- 執行 `node mesh.test.cjs` 驗證解析與面積。檔案上傳流程另已於開發機完成瀏覽器驗證。

直接以瀏覽器開啟 `index.html`，不需安裝套件或網路連線。請將同資料夾的 `model.js`、`app.js`、`style.css` 一起保留。

輸入尺寸、峰谷深度、波浪數與片數，即時顯示曲面預覽。拖曳預覽可旋轉；格線為列印分塊示意。調整成本、時間、材料利用率、造型與能源權重，比較木作、3D 列印、混合工法。展開進階參數可替換報價、產能與損耗；CSV 可匯出比較及全部輸入。設定保存在目前瀏覽器本機。

計算方式與來源詳見網頁底部。所有商業報價、工時、損耗、品質與設備參數是教學暫估，非市場調查。模型適用概念階段比較，未驗證構造、接合、實際列印分塊和安裝性能，不產生可直接施工的模型。再生塑膠預設為 PET 情境；塑膠單價應涵蓋料源處理費用，耗電獨立列出，避免重複計價。木作成本應填入含骨架之材料報價。

執行模型檢查：`node model.test.cjs`。此為可離線使用的原始碼，尚未部署至網際網路。
