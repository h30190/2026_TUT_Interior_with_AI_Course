# 材適：獨立的 3D 列印材料場域比較工具

## 檔案估算

頁面「00 上傳估算檔案」可選 STL/OBJ 模型或 PNG/JPG/WEBP 圖片。模型必須三角化，限20MB與10萬面。原始單位可選 mm/cm/m，可等比例縮放並預覽。

- 單一封閉且邊方向一致、沒有退化面的模型：可以完整實心體積估料。這是拓撲初檢，未檢查自交，非完整CAD實體驗證。不支援多個分離殼體實心相加，避免重疊或巢狀體重複計算。
- 開放、不連續、非流形或方向不一致模型：自動選薄殼模式，以總表面積×指定表皮占比×厚度近似估量。不可用此方式直接宣稱可列印；需校正內外表面重複、肋條和接頭。
- 實心體積不是低填充率的列印量；需要更接近生產的用料時，可手動貼入切片軟體的實際材料體積。
- 圖面可在預覽點兩點校正比例，或填實際寬高、輪廓占比、曲面倍數、厚度。圖片不會辨識尺寸標註或還原深度；效果圖有透視時請自行補入設計尺寸。
- 有效估算會自動帶入單件cm³，連動材料重量、成本、時間、能源和推薦。CSV保留檔名、計算基準及所有檔案參數。
- 上傳內容僅在本機解析，不傳到伺服器、不存進localStorage；重新整理須重選。退出檔案模式會還原先前手動體積，檔案體積不會靜默保存成手動輸入值。

`sample-block.obj` 為200×100×50mm實心方塊，體積1000cm³、表面積0.07m²，可直接測試。PDF/DWG/SKP請先轉成支援格式。

檔案幾何檢查：`node geometry.test.cjs`。瀏覽器上傳流程已於開發機完成驗證。

直接用瀏覽器開啟 `index.html`，同資料夾保留 materials.js、app.js、style.css。無網路也可計算，來源連結需網路。此工具僅比較 FDM/FFF 塑膠材料，不修改原有波浪壁板工具。

場域選乾燥、潮濕、窗邊、半戶外或直接淋水；設定最高預估使用溫度、熱篩選裕量、剛柔性、印表機設備。輸入成品實際材料體積或單面表皮面積與厚度、數量，再調整費用／製程假設與四項偏好。顯示初步候選、待確認和條件不符，只有初步候選參與排序。全部無法符合時顯示原因，不強行推薦。

比較 PLA、PETG、ASA、聚醚型 TPU95A、PA11-CF 與批次未確認的再生 PET。物性綁定特定 Prusament 牌號，來源與證據等級 C 列於頁面；再生 PET 論文證據 A 僅支持再製可行性，不能作為任意再生批次性能依據。成本、速率、耗損、功率、乾燥與再生含量全為明示可編輯情境假設。HDT 統一1.8MPa條件，非長期使用溫度。本工具沒有驗證產品承載、防火、排放或耐候認證。

CSV 匯出含結果、原因、共用設定、個別材料參數與來源。設定保存在此瀏覽器 localStorage，可恢復預設。

研究查閱日期2026-10-17，完整網址在 materials.js 與網頁內。主物性資料來自同一廠商，是單一來源限制；ASA 耐候另交叉比對 Polymaker。研究 skill 使本工具明確區分原生牌號、未知再生料、文獻數值與情境假設；未知性能不猜測、不參與推薦。
