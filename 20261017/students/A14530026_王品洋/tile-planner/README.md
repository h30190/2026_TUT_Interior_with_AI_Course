# 磁磚計畫產生器

輸入房間、門窗、給排水點與材質表，選好貼法，輸出：

1. **平面磁磚計畫建議書＋圖**（含起始磚放樣點、落水孔、洩水坡度、門檻斷面）
2. **立面磁磚計畫建議書＋圖**（四面牆各一張，含門窗洞口、給排水開孔、收邊條）
3. **3D 模擬圖**（單檔離線，滑鼠拖曳旋轉、滾輪縮放）
4. 建議書內有：**磁磚片數、用量、損耗、黏著劑用量、收邊條用量、各種貼法比較**

單一 HTML 檔，雙擊 `磁磚計畫.html` 就能用，不需要網路。

## 怎麼用

1. 打開 `磁磚計畫.html`，左邊是表單，右邊即時產生建議書（改任何欄位都會重算）。
2. 依序填：① 房間 → ② 落水孔與洩水 → ③ 門窗 → ④ 給排水點 → ⑤ 磁磚表 → ⑥ 收邊條與門檻 → ⑦ 施工選項。
3. 「施工選項」可以指定貼法與起始點，也可以選「自動」讓系統挑片數最省（有洩水的地面會優先讓落水孔對正磚縫）。
4. 上方按鈕：載入範例、存／讀專案 JSON、下載建議書（HTML）、下載 3D 圖、列印成 PDF。

座標約定：原點在房間**西北角（粗胚面）**，x 往東、y 往南；牆上位置，北牆與南牆自西端量起，東牆與西牆自北端量起；z 自結構樓板往上。單位 cm（磚厚 mm）。

> 平面圖、立面圖是圖面，程式不讀圖檔。把圖上的尺寸抄進表單即可（`sample-project.json` 是範例專案格式）。

## 固定規則（業主指定）

| 規則 | 實作 |
|---|---|
| 磁磚縫一律 0.2 cm | 磚距＝磚寬＋0.2；表單上固定、不可改 |
| 黏著劑厚 0.5 cm | 立面扣除用、黏著劑用量用；固定 |
| 立面要扣磁磚厚度與黏著劑厚度 | 牆磚完成厚＝磚厚＋0.5 cm。**轉角收法**：預設長牆通到底、短牆兩端被夾住各扣一次；可改成「每面牆兩端都扣」（保守）。地面淨區域也依「施工順序」扣除或不扣 |
| 起始磚放樣點必須標註 | 平面圖、立面圖都畫紅色十字與放樣線，建議書寫出座標與距淨邊距離 |
| 平面要注意落水孔與洩水坡度 | 落水孔開孔磚計數、洩水方向箭頭、最大落差、找坡砂漿量、單片磚面高低差檢查（> 3 mm 警告並建議磚尺寸） |

## 貼法

對縫正貼（橫貼／直貼）、1/2 交丁（橫／直）、1/3 交丁（橫／直，長方磚）、45° 斜貼（正方磚）、人字拼（長邊約為短邊整數倍的長方磚）。
每種貼法都用「真的把每一片磚排出來、再裁切到貼磚區」的方式算片數，不是用面積除一除，所以切磚數、細條切磚、最小切邊都是真的排出來的結果。

## 計算說明與假設

- **片數**：每一片被切到的磚都算一整片（不計餘料再利用），是保守估計。**損耗率**＝（實際片數 × 單片面積 − 實際貼磚面積）÷ 實際貼磚面積，磚縫面積不算進去。**採購**＝實際片數＋破損預留（預設 3%）。
- **細條切磚**：切邊 < max(4 cm，磚短邊 20%) 視為細條。
- **黏著劑**：淨貼磚面積 × 0.5 cm × 耗量係數（預設 1.6 kg/m²/mm，可改）。
- **收邊條**：門洞口（兩側＋頂）、窗洞口（四邊）、牆磚未貼到天花板時的頂端、另外輸入的陽角；加損耗後除以單支長度進位。
- **洩水**：點收水時，單片磚面高低差＝坡度 × 磚對角線；建議 ≤ 3 mm。這是建議值，不是法規。
- 起始點候選：四個角、房間中心（磚中心／十字縫）、門口對齊、落水孔中心（磚中心／十字縫）；牆面有左右下上、牆中心、窗中心。

## 已知限制

- 只支援**矩形房間**；沒有柱、凸牆、斜牆、L 形。
- 地面只有**一個落水孔**；給排水點只在牆上，孔以正方形外框近似。
- 沒有計價、填縫劑、防水層。
- 不同牆之間不互相利用餘料。
- 人字拼假設磚長約為磚寬的整數倍，非整數倍時近似。

## 檔案

```
磁磚計畫.html          單檔成品（node build.js 產生）
sample-project.json    範例專案（可在網頁上「載入 JSON」）
src/engine.js          計算核心（純函式，不碰 DOM）
src/draw.js            平面圖、立面圖、斷面圖、縮圖、3D 檢視器
src/report.js          建議書排版
src/app.js             表單與事件
build.js               把 src 內嵌成單一 HTML
test/engine.test.js    計算核心測試
test/run-ui-test.js    介面測試（用 Edge 開網頁、模擬使用者操作）
screenshots/           截圖證據
```

## 測試

```bash
node build.js                 # 重新打包
node test/engine.test.js      # 計算核心：46 項
node test/run-ui-test.js      # 介面：22 項（需要 Edge）
```

**計算核心 46 項**分三類：

- **手算答案**：磚距、片數、整磚與切磚數（例：177.3 × 237.3 cm、30×30 磚 → 48 片＝35 整磚＋13 切磚）、立面扣除 1.35 cm、洩水落差、黏著劑 8 kg/m²、收邊條支數。
- **性質測試（隨機輸入）**：每種貼法的磚互不重疊、磚能蓋滿區域、片數 ≥ 理論下限、平移不變、橫貼直貼對稱、磚越大片數越少、400 組隨機專案不丟例外也沒有 NaN。
- **壞值**：19 種輸入（空白、負數、門超出牆長、洞口重疊、落水孔在房外…）都要被擋下並說明。

寫測試時抓到並修掉的真問題：

1. 損耗率出現負數（淨面積含磚縫、磚片面積不含）→ 改用「實際貼磚面積」。
2. 指定的起始點在該面不存在時當掉（例如沒有窗卻選「窗中心對正」）。
3. **欄位空白被默默換成預設值**（房間寬留白，程式不報錯，用 180 去算）→ 空白一律視為錯誤。
4. 磁磚表是空的時當掉。
5. 重畫報告時 3D 畫布被一起清掉，第二次修改輸入就丟例外（介面測試抓到）。

## 真實案例：一樓後浴室（real-case/）

`real-case/一樓後浴室.project.json` 是依 A-08／A-09 圖面（1/30）量出來的專案，網頁上按「載入 JSON」即可。`node real-case/run.js` 會印出片數對照。

- 房間 120×270×320 cm、落水孔 (62,78)、東牆橫拉門 100×230（自北端 170）、北牆橫拉窗 60×57（窗台 159）。這些是從圖面像素換算（圖上沒有標註數字），誤差約 ±1–2 cm，請現場複量。
- 地磚三洋 MSY-R3540 30×30、牆磚三洋 HF3660600 30×60（材質確認表）；磚厚、每箱片數圖上沒有，暫用 9 mm／8.5 mm／11／6。
- 地磚正貼：程式算出 **36 片**，與圖面材料表一致。牆磚二分之一交丁：圖面寫 98 片，程式依牆高 320 算 152 片（牆高 200 cm 約 93 片），差異來自圖面未註明貼磚高度。
- 圖面的斜牆以矩形近似；馬桶糞管孔（地面 4"）目前不支援，未納入開孔。
- 給水點高度圖上沒有，為假設值。
