# 空間家具配置 + 風水檢查

以程式運算處理「尺寸、動線、禁忌」這類可以量化的規則，再由 Claude 補上腳本無法判斷的設計考量，最後用平面圖與白話說明呈現結果。

## 檔案

| 檔案 | 用途 |
|------|------|
| `scripts/layout.py` | 核心工具：`catalog` 列出家具型錄、`check` 檢查配置、`optimize` 自動產生方案（只用標準函式庫） |
| `references/input-format.md` | **撰寫 JSON 前必讀**：座標系統與欄位說明 |
| `references/ergonomics.md` | 家具尺寸、淨空規範與需人工判斷的項目 |
| `references/fengshui-rules.md` | 風水規則、傳統說法與實際理由、化解方式 |
| `examples/` | 範例輸入（臥室、客廳）與輸出 |

## 工作流程

### 1. 收集資訊

需要以下資訊。若缺少，**一次問完**（最多 3 題）；次要資訊用合理預設值並註明：

- **房間尺寸**（必要）：寬 × 深，單位公分。使用者說「坪」時，1 坪 ≈ 3.3 m²，但仍需要長寬比例
- **門窗位置**（必要）：在哪面牆、離牆角多遠、多寬。要區分房門和廁所門
- **樑的位置**：有樑才需要
- **家具清單**：沒提供時，依房間用途給預設清單（臥室：雙人床、床頭櫃 ×2、衣櫃；書房：書桌、書櫃）
- **目的**：已經擺好、想檢查（→ check），還是想要建議方案（→ optimize）

使用者提供平面圖照片或手繪圖時，先從圖中估計尺寸並列出你的判讀結果，請使用者確認後再計算。

### 2. 撰寫輸入 JSON

先讀 `references/input-format.md`，再把資訊轉成 JSON 存檔。特別注意：
- 以**圖面上方為北 (N)**，除非使用者給了實際方位
- 門窗的 `offset`：北、南牆從西端量起；東、西牆從北端量起
- 家具的 `facing` 是**正面**方向，床的正面是床尾

### 3. 執行腳本

```bash
# 檢查現有配置
python scripts/layout.py check room.json --svg check.svg

# 自動產生 3 個方案（輸出 plan_1.json / plan_1.svg ...）
python scripts/layout.py optimize room.json --top 3 --out-dir plans --seed 1
```

- 腳本位於本 Skill 資料夾內，執行時使用完整路徑
- 若 `python` 無法執行或沒有任何輸出（例如 Windows 的 Microsoft Store 捷徑），依序改用 `python3`、`py`、`uv run --no-project python`
- 需要結構化結果時加上 `--json`
- 家具尺寸與型錄不同時，在 JSON 用 `width` / `depth` 覆寫
- optimize 沒有找到可行方案時，會提示減少家具或確認尺寸；請告知使用者，並建議縮小家具或刪減項目

### 4. 判讀與補強

腳本只處理可量化的規則，你要負責：

1. **檢查結果是否合理**：確認平面圖和使用者描述一致。若發現 JSON 寫錯（例如門畫到錯的牆），修正後重新執行
2. **補充人工判斷**：依 `references/ergonomics.md` 與 `references/fengshui-rules.md` 的「需要人工判斷」段落，加入插座、採光、冷氣等建議
3. **微調方案**：如果方案有可以輕易改善的問題，手動修改 `plan_N.json` 後用 `check` 驗證，不要只丟出腳本的原始結果
4. **化解建議**：無法用移動家具解決的風水問題（例如房間只有一面牆能放床），提供 `fengshui-rules.md` 中的化解方式

### 5. 回覆格式

```
## 房間條件
（尺寸、門窗、樑的判讀結果，一句話說明座標假設）

## 推薦方案
（附上平面圖；用表格比較各方案：總分、人體工學分、風水分、優點、缺點）

## 問題與建議
（依嚴重程度排序；每個問題寫：是什麼、為什麼（傳統說法＋實際理由）、怎麼改）

## 補充建議
（腳本以外的考量：插座、採光、冷氣、收納等）
```

**平面圖一定要讓使用者看到**，這是本 Skill 最重要的輸出：
- 把 SVG 存在使用者看得到的位置（目前的工作資料夾，不要放在暫存目錄）
- 有傳送檔案、顯示圖片或預覽的工具時，主動把每個方案的 SVG 顯示給使用者
- 都沒有時，告訴使用者檔案的位置，並說明可用瀏覽器（Edge、Chrome）開啟 SVG

## 原則

- **實用優先於風水**：總分中人體工學佔 60%。不要為了避開低等級的風水禁忌，犧牲走道或動線
- 風水是傳統文化與居住心理的參考，不是科學定論。語氣要平實，不渲染恐懼，不說「一定會生病、破財」
- 每個禁忌都盡量搭配實際理由，例如門沖床 → 缺乏隱私、容易被驚醒
- 尺寸以公分為單位；對使用者說明時可以加註台尺（1 台尺 ≈ 30.3 cm）
